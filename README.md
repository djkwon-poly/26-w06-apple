# 🍎 사과게임

숫자가 적힌 사과를 이어 수확하는 1분 퍼즐 게임입니다.

## 게임 소개

8×8 격자에 1부터 9까지의 숫자가 사과 아이콘과 함께 표시됩니다. 게임을 시작한 뒤 상하좌우로 인접한 사과를 드래그해 선택하고, 합이 10의 배수가 되면 손을 떼어 수확하세요. 선택한 숫자의 합만큼 점수를 얻습니다.

수확한 사과 위에 있던 사과는 아래로 내려오고, 빈 윗칸에는 새 사과가 채워집니다. 60초 동안 높은 점수에 도전해 보세요. 최고 점수는 현재 브라우저에 저장되며, 새 기록을 세우면 컨페티가 펼쳐집니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 각각 별도 파일로 구성했습니다. Copilot Agent에 게임의 기본 규칙과 화면을 요청한 뒤, 사과 아이콘, 드래그 선택 강조, 열 단위 낙하, 기록 갱신 효과와 숫자 가독성을 차례로 다듬었습니다.

- `index.html`: 게임 화면과 점수·시간 표시
- `style.css`: 반응형 격자, 선택 상태, 사과 낙하와 컨페티 애니메이션
- `script.js`: 보드와 드래그 판정, 점수·타이머, 최고 점수 저장

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 빌드나 패키지 설치는 필요하지 않습니다.

## 커스터마이징한 부분

- 제한시간을 1분으로 설정하고, 성공 조건을 합계 10뿐 아니라 모든 10의 배수로 확장했습니다.
- 숫자를 사과 아이콘과 숫자 배지로 표현하고, 선택 경로를 드래그 중 강조합니다.
- 수확 후 각 열의 사과가 아래로 떨어지고 새 사과가 위에서 채워지도록 했습니다.
- 최고 점수를 브라우저에 저장하고 새 기록에 컨페티 효과를 추가했습니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
